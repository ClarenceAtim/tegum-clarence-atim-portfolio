# Tegum Clarence Atim — Portfolio

Personal portfolio website for Tegum Clarence Atim, Data Scientist working in Machine Learning and Generative AI on AWS, MLOps and DevOps.

## What's on the site

- Home, About, Projects, Blog, Contact and Privacy Policy
- Projects: Mobile Money Fraud Detection API (live), CV-to-JD Matcher and DevOps pipeline (next builds), and SIDEKOM
- Blog: step-by-step tutorials and tech news in Machine Learning, MLOps, DevOps and AWS, with one category and keyword tags on every post
- Download CV button

## Run it locally

Open `index.html` in a browser, or serve the folder with any static file server, for example:

```bash
python3 -m http.server
```

## Deploy

The site is a single static page (`index.html`, no build step). It deploys as a static site from the `main` branch.
